# 网络学堂自动登录插件

这是一个用于清华统一身份认证和网络学堂自动登录的 Tampermonkey（或类似用户脚本管理器）用户脚本。

脚本近期已从“首次保存并本地加密凭证”改为“在脚本中以明文变量写入账号/密码”的方式，以便直接使用并方便管理。请小心保存脚本文件，避免他人访问你的凭证。

主要功能：

- 直接在脚本中配置账号/密码（明文），脚本会自动填充登录表单并点击登录按钮。

---

## 安装（快速）

1. 在浏览器中安装 Tampermonkey（或 Violentmonkey / Greasemonkey）：
   https://www.tampermonkey.net/
2. 新建脚本，删除模板内容。
3. 打开仓库内的 `tsinghua-auto-login-save.user.js`，将整个文件内容复制并粘贴到 Tampermonkey 编辑器中，然后保存并启用脚本。

---

## 配置账号/密码

脚本在顶部包含一个 `ACCOUNTS` 数组，用来直接存放一个或两个账号密码，例如：

```javascript
var ACCOUNTS = [
	{ user: '2023012345', pass: '12345678' }
];
```

请把上面的 `user` 和 `pass` 替换为你自己的学号/密码或需要登录的账号。
